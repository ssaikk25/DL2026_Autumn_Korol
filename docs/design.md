# Проектирование: «Погода с настроением»

Документ описывает проектирование fullstack-приложения «Погода с настроением» и соответствует
части 1 тестового задания.

## 1. Обзор продукта

«Погода с настроением» — развлекательное веб-приложение о погоде. Пользователь вводит название
города или разрешает определение геолокации; приложение показывает текущую погоду и подбирает под
неё релевантный мем. Мемы можно оценивать (`👍` / `👎`), менять на другой и делиться «открыткой»
(погода + мем) через соцсети или скачиванием PNG.

Продуктовая ценность: превращает утилитарную сводку погоды в живой, персонализированный опыт,
который удерживает пользователя и даёт повод вернуться.

## 2. Пользовательские сценарии

- **US-1.** Как пользователь, я хочу ввести название города и увидеть текущую погоду вместе с
  подобранным мемом, чтобы за один заход получить и информацию, и настроение.
- **US-2.** Как пользователь, я хочу оценивать мемы и запрашивать альтернативный вариант, чтобы
  со временем видеть более смешные мемы под мою погоду.
- **US-3.** Как пользователь, я хочу поделиться «открыткой» (погода + мем) в соцсетях или скачать
  её, чтобы отправить друзьям.
- **US-4 (опционально).** Как пользователь, я хочу видеть прогноз на несколько дней с мемом на
  каждый день, чтобы планировать и получать порцию настроения заранее.

## 3. Функциональные требования

### 3.1 Фронтенд

Обязательные:

- Поиск города с автодополнением (выпадающий список).
- Кнопка «Моя локация» на основе браузерной геолокации.
- Карточка текущей погоды: температура, «ощущается как», влажность, ветер, облачность, описание.
- Карточка мема: изображение, кнопки оценки `👍` / `👎`, кнопка «Другой мем».
- Шаринг: скачивание открытки (PNG) и Web Share API / копирование ссылки.
- Индикация загрузки и понятные ошибки (город не найден, сеть недоступна, демо-режим).
- Лёгкие анимации смены мема и фон-градиент, зависящий от категории погоды.

Опциональные:

- Лента прогноза на 5 дней с мемом на каждый день.
- Форма добавления пользовательского мема.
- Раздел «Топ мемов».

### 3.2 Бэкенд

Обязательные:

- Прокси геокодинга (поиск города по названию).
- Прокси погоды (текущая и прогноз) с кэшированием.
- Детерминированная категоризация погоды по WMO-коду и порогам.
- Выдача мемов по категории с ранжированием рекомендателем.
- Приём оценок мемов и обновление параметров рекомендателя.
- Единый формат ошибок и валидация входных данных.
- Demo-fallback (детерминированные моковые данные) при недоступности внешнего API.

Опциональные:

- Добавление мемов пользователями с автоматической категоризацией.
- Админ-токен для управления набором мемов.
- Эндпоинт «Топ мемов».

## 4. Проектирование API

### 4.1 Общие соглашения

- Базовый путь: `/api`.
- Формат: JSON, кодировка UTF-8.
- Ошибки: соответствующий HTTP-код и тело `{"detail": "<сообщение>"}`.
- Чтение не требует авторизации; запись мемов — опциональный заголовок `X-Admin-Token`.

### 4.2 Эндпоинты

| Метод | Путь | Параметры | Ответ |
| ----- | ---- | --------- | ----- |
| GET | `/api/health` | — | `{status, version}` |
| GET | `/api/geocode` | `q` (str), `limit` (int, по умолчанию 5) | `{results: [{name, country, admin1, latitude, longitude, timezone}]}` |
| GET | `/api/weather/current` | `city` (str) **или** `lat`+`lon` (float) | `{location, current, meme, is_demo}` |
| GET | `/api/weather/forecast` | `city` **или** `lat`+`lon`, `days` (int, по умолчанию 5) | `{location, days: [{date, weather_code, temp_min, temp_max, category, meme}]}` |
| GET | `/api/memes` | `category` (str, опц.), `limit` (int, по умолчанию 10) | `{memes: [{id, image_url, category}]}` |
| POST | `/api/memes` | multipart: `image` (file), `description` (str), `category` (str, опц.) | `{meme: {...}}` |
| POST | `/api/memes/{id}/feedback` | `{vote: "up"\|"down", category: str, weather_context: dict}` | `{meme_id, likes, dislikes, alpha, beta}` |
| GET | `/api/memes/top` | `category` (опц.), `limit` (по умолчанию 10) | `{memes: [...]}` |

Формат `current` в ответе `/api/weather/current`:

```json
{
  "temperature": 12.3,
  "apparent_temperature": 10.1,
  "humidity": 67,
  "wind_speed": 4.2,
  "cloud_cover": 80,
  "pressure": 1012,
  "weather_code": 61,
  "description": "Небольшой дождь",
  "category": "rain"
}
```

## 6. ML-подсистема

### 6.1 Общий пайплайн

Подбор мема состоит из трёх компонентов:

1. **Офлайн, при инициализации (seed).** Из датасета `rumeme-desc` детерминированным
   keyword-отбором со списком исключений выбираются погодные мемы и раскладываются по категориям.
   Датасет общий (погодных мемов меньшинство), поэтому чистый zero-shot дал бы шум.
2. **Zero-shot категоризация (для открытых текстов).** Мемы, добавленные пользователями без
   явной категории, категоризируются по семантической близости описания к якорным текстам.
3. **Онлайн, при запросе.** Погода преобразуется в категорию детерминированной функцией, затем
   внутри категории рекомендатель выбирает мем, дообучаясь на оценках пользователей.

### 6.2 Эмбеддинги и zero-shot категоризация

Для русского текста семантическая близость считается эмбеддингами, а не TF-IDF, поскольку
описания мемов и погодные условия редко совпадают дословно (`дождь` против `мужчина с зонтом`).

- Основной кодировщик: `fastembed` (ONNX, мультиязычная модель, без зависимости от PyTorch).
- Резервный вариант: TF-IDF + cosine similarity, если модель недоступна.
- Якоря категорий (русскоязычные описания): «жара, солнце, пекло», «дождь, зонт, лужи»,
  «снег, мороз, зима», «ветер, шторм, ураган», «холод, заморозки», «комфортная, ясная погода».
- Категория назначается по максимальному косинусному сходству с якорем.

Эмбеддинги применяются для авто-категоризации пользовательских мемов (`POST /api/memes` без явной
категории). Seed-выборка строится детерминированным keyword-отбором со списком исключений — на
общем датасете это надёжнее чистого zero-shot.

### 6.3 Рекомендатель: Thompson sampling

Для каждого мема ведётся бета-распределение с параметрами `α` и `β`. При показе для категории
для каждого кандидата сэмплируется значение из `Beta(α, β)` и выбирается максимум. Оценка
пользователя обновляет параметры: `up` → `α += 1`, `down` → `β += 1`.

Преимущества: простое онлайн-обучение без отдельного этапа тренировки, баланс
exploration/exploitation, понятная интерпретация.

### 6.4 Данные и обучение

- Исходные данные: датасет `foldl/rumeme-desc` (2508 русских мемов, колонки `image` и `text`,
  лицензия CC BY-SA 4.0). В проект попадает подмножество.
- Исследование и эксперименты ведутся в Jupyter-ноутбуках (`notebooks/`), воспроизводимая
  версия вынесена в скрипты `backend/app/ml/`.
- Рекомендатель не требует предварительного обучения — параметры обновляются на живых оценках
  и хранятся в таблице `meme_stats`.

## 7. Ключевые технические решения

| Компонент | Выбор | Обоснование |
| --------- | ----- | ----------- |
| Frontend | React 18 + TypeScript + Vite | Компонентная модель, типизация, быстрая сборка; не «чистый js+html+css», но и не тяжёлый стек |
| Стилизация | Tailwind CSS | Быстрая верстка, консистентный дизайн, малый бандл |
| Backend | FastAPI + Uvicorn | Асинхронность, автогенерация OpenAPI-документации, нативный Python для ML |
| Валидация | Pydantic v2 | Строгая типизация запросов/ответов |
| БД | SQLite + SQLAlchemy 2.0 | Файловая, без отдельного сервера, кросс-платформенная, достаточна для масштаба |
| Эмбеддинги | fastembed (ONNX) | Настоящие мультиязычные эмбеддинги без веса PyTorch |
| Рекомендатель | NumPy | Бандит реализуется без внешних ML-библиотек |
| Погода | Open-Meteo | Бесплатно, без ключа, геокодинг + погода в одном поставщике |
| Провайдер погоды | Интерфейс `WeatherProvider` | Лёгкая замена на OpenWeatherMap через `.env` и новый адаптер |

## 8. Нефункциональные требования

- **Кросс-платформенность:** сборка и запуск на Linux и Windows.
- **Отказоустойчивость:** при недоступности погодного API отдаётся детерминированный mock
  с флагом `is_demo`.
- **Производительность:** кэширование ответов погоды (TTL 10 минут), ленивая загрузка эмбеддингов.
- **Лицензионная чистота:** атрибуция датасета мемов (CC BY-SA 4.0) в README.
- **Читаемость кода:** разделение на слои (routers, services, models), комментарии в неочевидных местах.
